Local-first · zero runtime dependencies

See what your weekly Codex grant is worth.

weeklygrant reads local Codex session history, prices token usage, and pairs it with observed quota movement to produce a transparent API-equivalent planning estimate.

Install from npm View source on GitHub

A useful signal from local history

Quota-aware

Handles weekly and five-hour windows, resets, plan changes, and separate quota streams.

Correct accounting

Prices cached input, uncached input, output, long context, and Fast service tiers.

Inspectable

Shows confidence, diagnostics, observed spend, model usage, charts, and machine-readable JSON.

Try it in seconds

$ npx weeklygrant Scanning Codex sessions and pricing tokens… Estimated weekly API value $63.05 medium confidence · 5% quota used · reset in 167h $ npx weeklygrant --json --redact # complete report for scripts, dashboards, and audits

Estimates with their limits visible

The value is API-equivalent planning data, not a Codex bill, credit balance, guaranteed spending maximum, or subscription entitlement. Early estimates are labeled low confidence; missing prices are never treated as free usage.
